### 4. Jalur yang Dipakai, Kendala, dan Solusi

**Jalur yang Dipakai**

Praktikum Modul 01 dilakukan menggunakan Google Colab untuk menjalankan perintah Git, sedangkan GitHub digunakan untuk menyimpan repository proyek secara online.

**Kendala yang Ditemui**

Kendala yang ditemui adalah proses autentikasi saat menghubungkan repository lokal dengan GitHub. Untuk melakukan push ke GitHub, diperlukan autentikasi agar perubahan dapat dikirim ke repository online.

**Solusi**

Kendala tersebut diatasi dengan menggunakan Personal Access Token (PAT) sebagai metode autentikasi saat melakukan push dari Google Colab ke GitHub. Setelah proses push berhasil, repository dan file proyek dapat dilihat di GitHub.
